# Repository Support

`fusion-skills` is a community-driven, open source project which provides AI coding assistant skills for building CrowdStrike Falcon Fusion workflows. `fusion-skills` is an open source project, not a CrowdStrike product. As such, it carries no formal support, expressed or implied.

## Issue Reporting and Questions 🐛

Issues may be reported [here](https://github.com/CrowdStrike/fusion-skills/issues/new/choose) and are used to track bugs, documentation and link updates, enhancement requests, and security concerns.

### Issue Formatting (MCVE)

Whenever possible, please format issues and questions in the [**M**inimal, **C**omplete, and **V**erifiable **E**xample](https://stackoverflow.com/help/minimal-reproducible-example) format. This reduces "noise", helps the community understand your concern, and gets you a solution more quickly. It also reduces the likelihood of confidential environment details being shared accidentally.

MCVE-formatted examples should be:

- **Minimal**: provide as little code/configuration as possible to reproduce the problem.
- **Complete**: provide all the pieces needed to recreate the issue, with complete error messages and tracebacks. Use code blocks, not screenshots.
- **Verifiable**: provide input that reliably reproduces the problem.

**Never include real credentials, API keys, customer data, or CID-specific identifiers** in an issue. Mock sensitive values.
